# 断点续传

`report_transfer_session` 保存文件、Chunk 数量、已上传字节、状态和完整 SHA-256；`report_transfer_chunk` 以 `(session_id, chunk_index)` 唯一。Mock Receiver 提供 init/status/chunk/complete 接口，重复 Chunk 只有 SHA-256 相同时才幂等成功，冲突返回 409。客户端恢复时合并本地数据库和服务端状态，从第一个缺失 Chunk 继续，完成后比较本地/远端 SHA-256。

生产 HTTP 默认应使用 HTTPS。端点表只保存凭据引用/加密值，列表 API 不返回 token、密码或私钥。正式卫健委断点协议和证书由部署方提供后再配置。
