## 业务主链约束

正常页面创建的任务走 Gateway 主链：`上报任务 → 预审核 → 生成上报文件 → 开始上报`。预审核存在错误时任务为 `已阻断`，生成和发送接口拒绝继续执行；旧批次接口仅作为兼容能力保留。

## 外部依赖边界

多平台页面和安全传输页面提供真实配置与演示链路；正式主管部门生产地址、证书和厂商切片 SDK 仍需由部署环境提供。SVS 依赖 slide-worker/OpenSlide，TRON/HWP 等厂商格式依赖对应 vendor 镜像能力。
