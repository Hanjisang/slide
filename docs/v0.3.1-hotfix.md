# v0.3.1 Hotfix

## 监控告警

本版本新增 `MonitoringSnapshotService`，统一提供 components、resources、storageTargets、tasks、queues、parserCapabilities 和 criticalAlerts。`/api/system/health`、`/api/system/metrics`、`AlertService` 和前端全局轮询不再各自采样。

告警规则扩展到基础服务、CPU/内存/磁盘/JVM、Storage Target、任务失败/卡住和队列积压。规则的触发阈值、恢复阈值和防抖次数来自 `alert_rule`；事件记录首次/最后出现、出现次数、异常/健康采样和自动恢复信息。

MySQL 不可用时，健康接口仍返回 `mysql=DOWN`，`InMemoryCriticalAlertBuffer` 暂存故障时间并在数据库恢复后补录事件。前端 AppLayout 每 30 秒轮询活动告警和健康快照，使用 sessionStorage 按事件去重，并显示告警铃铛和活动数量。

## TRON

本机已收到 `go-parser/tron.zip`，其中包含 Linux `libtronc.so` 及 Windows DLL。Linux 库已解包到被 Git 忽略的 `vendor-libs-local/tron/libtronc.so`，Go Parser 通过 `TRON_SDK_PATH` 和 `dlopen/dlsym` 校验公开 API 符号。由于压缩包没有头文件/ABI 文档和真实 `.tron` 样本，当前仍为 `SDK_PRESENT` 但不可宣称 `AVAILABLE`，TRON 解析器暂不调用未知 ABI。

## HWP

本机已收到 `go-parser/hwp.zip`，其中包含 Linux `libhwp_sdk.so` 及 Windows 运行库。Linux 库已解包到被 Git 忽略的 `vendor-libs-local/hwp/libhwp_sdk.so`。HWP 已接入可选 CGO 适配器：读取配置、缩略图、标签图、预览图和分层 Tile；SDK 通过 `HWP_SDK_PATH` 运行时加载。没有真实 `.hwp` 样本，因此当前只能显示 `SDK_PRESENT`，不能宣称 L3-L5 `AVAILABLE`。

## 验证边界

本环境已完成 Maven、Python、前端构建和 Go 单元测试。真实 HWP/TRON 文件仍未提供；HWP 的动态适配器和 TRON 的 SDK 探测尚未完成 L3-L5（metadata、thumbnail、多个层级 Tile、浏览器）验收。
