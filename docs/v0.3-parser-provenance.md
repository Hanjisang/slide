# v0.3 Parser 代码来源记录

## 来源

- 输入：用户提供的 `parser.zip`。
- 原始形态：`imageparser` 项目的 `parser` 子模块，不是可独立构建的 Go 工程。
- 原目录包含 KFB、TMAP、TMAP01、MDSX、DMETRIX、FENLAN、ZYP、SDPC、CSP、HWP、TRON、OpenSlide 及其他本阶段无关格式。
- 原归档未提供 LICENSE、NOTICE、COPYING 或等价授权文件：`LICENSE_NOT_PROVIDED`。

本记录只描述来源，不为原代码、SDK、样本或当前仓库创造任何许可证或再分发授权。

## 本项目的整理

本项目在 `go-parser/` 新建独立 module `imageparser`，完成以下工程化工作：

- 仅迁移 KFB、TMAP06/TMAP07、MDSX、DMETRIX、FENLAN、ZYP、SDPC 的目标算法；
- 重建最小 `types`、图像工具和基于 `os.File.ReadAt` 的本地 Streamer；
- 新建显式 Registry、HTTP Service、ParserCache、每切片互斥锁和统一 256 JPEG 输出；
- 增加路径、读取、尺寸、索引、分配、输出、panic 与超时边界；
- 将 SDPC HEVC 从结构解析中隔离，使缺 decoder 时服务仍可构建和启动；
- 用每像素有界颜色校正替代原 SDPC 无界全局三维颜色表缓存；
- 没有复制原远程 Streamer、配置中心、网络缓存和无关格式实现。

核心格式算法尽量保留原结构；服务边界、错误模型、缓存和安全限制是本项目新增。

## 验证边界

仓库内没有十种厂家格式的真实样本，因此迁移代码只具备构建、安全失败和服务路由证据，不具备 L3-L5 实文件证明。SVS 的真实解析由原有 OpenSlide 路径完成，不属于本次迁移代码来源。
