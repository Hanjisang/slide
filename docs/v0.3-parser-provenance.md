# v0.3 Parser Provenance

现有 Go Native parser 源码随仓库提交；HWP/TRON 厂商归档按部署授权随仓库提交并只在 Docker 构建阶段提取 Linux 库，真实切片样本不进入 Git。

| Format | Source | In Git | Redistribution | Runtime path |
| --- | --- | --- | --- | --- |
| KFB/TMAP/MDSX/DMETRIX/FENLAN/ZYP/SDPC | 仓库 Go 源码 | 是 | 按仓库许可证 | 不适用 |
| CSP | 厂商 SDK（未提供） | 否 | LICENSE_UNCONFIRMED | vendor-libs-local/csp |
| TRON | `go-parser/tron.zip` | 是 | DEPLOYMENT_AUTH_REQUIRED | `/opt/vendor/tron/libtronc.so` |
| HWP | `go-parser/hwp.zip` | 是 | DEPLOYMENT_AUTH_REQUIRED | `/opt/vendor/hwp/libhwp_sdk.so` |

TRON/HWP 通过 Linux `dlopen/dlsym` 做符号探测，Windows DLL 不进入镜像。只有真实样本完成 metadata、thumbnail、tile 和浏览器显示验证后，格式状态才允许从 `SDK_PRESENT`/`TEST_DATA_REQUIRED` 变为 `AVAILABLE`。
