# v0.3 Parser Provenance

现有 Go Native parser 源码随仓库提交；原始第三方归档、厂商 SDK 和真实切片样本均未进入 Git。

| Format | Source | In Git | Redistribution | Runtime path |
| --- | --- | --- | --- | --- |
| KFB/TMAP/MDSX/DMETRIX/FENLAN/ZYP/SDPC | 仓库 Go 源码 | 是 | 按仓库许可证 | 不适用 |
| CSP | 厂商 SDK（未提供） | 否 | LICENSE_UNCONFIRMED | vendor-libs-local/csp |
| TRON | `libtronc.so`（本地忽略目录） | 否 | LICENSE_UNCONFIRMED | `TRON_SDK_PATH` |
| HWP | `libhwp_sdk.so`/`hwp_sdk.dll`（本地忽略目录） | 否 | LICENSE_UNCONFIRMED | `HWP_SDK_PATH` |

TRON/HWP 通过 Linux `dlopen/dlsym` 做符号探测，不复制到公开镜像。只有真实样本完成 metadata、thumbnail、tile 和浏览器显示验证后，格式状态才允许从 `SDK_PRESENT`/`TEST_DATA_REQUIRED` 变为 `AVAILABLE`。
