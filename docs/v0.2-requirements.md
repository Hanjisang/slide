## 外部依赖

- KFB、SDPC、TRON、MDSX、TMAP、DMETRIX、FENLAN、ZYP、HWP、CSP 的真实解析依赖厂商 SDK。
- 正式卫健委接口协议、签名方式、证书和接收地址未提供；当前使用可配置模板和 Mock HTTP 接收端验收。
