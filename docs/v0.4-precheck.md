# 上报预审核

规则存于 `report_precheck_rule`，执行实例和问题分别存于 `report_precheck`、`report_precheck_issue`。支持 REQUIRED、DICTIONARY/ENUM、REGEX、LENGTH、RANGE 等受控规则；规则错误使 Job 进入 `BLOCKED`。问题可记录本次上报值覆盖，覆盖操作写入 `report_data_override`，并要求 `REPORT_PRECHECK_OVERRIDE` 权限。重新审核创建新实例，只有错误数为零才进入 `READY`。

`ReportService.send` 和 v0.4 Job send API 都在后端检查 `precheck_status=PASSED`，前端状态不能绕过该闸门。
