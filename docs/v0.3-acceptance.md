## v0.2 回归边界

本次没有重写 Spring Boot、Vue、OpenSeadragon、MinIO、归档、权限或上报模块。v0.2 的归档、权限 403、病理 ZIP、备份和基础数据自动化测试继续通过。v0.3 重点重新验证了登录后的健康/能力页面、SVS metadata/thumbnail/Tile/OpenSeadragon 和 Go Down 降级；厂家格式上传后的真实 READY/阅片仍等待样本。
