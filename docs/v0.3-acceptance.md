## P36 修复

- OpenSlideAdapter 的 metadata 增加统一 `status=READY` 与 `format=SVS`，修复真实 SVS 上传后被 Backend 判为 `FAILED`。
- MDSX 按 XML `Rows=y`、`Cols=x` 校验并计算 tile index，覆盖非方形层级；服务保留其 512 block，并通过 `levels[].tileSize` 告知前端。
- OpenSeadragon 不再假设所有 adapter 的 level 数组方向一致，而是按宽度升序归一化，并读取实际 `tileSize`。
- 新增匿名统一验证器和坐标、图像、错误脱敏测试。
