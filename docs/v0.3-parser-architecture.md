# v0.3 多格式解析架构

## 调用链

```text
Browser
   |
Nginx :8088
   |
Spring Boot :8080
   |
Python Slide Worker :8000
   +-- SVS -----------------> OpenSlideAdapter
   |
   +-- Vendor formats ------> GoParserAdapter
                                  |
                             Go Parser :8100
                                  +-- KFB Native
                                  +-- TMAP06/TMAP07 Native
                                  +-- MDSX Native
                                  +-- DMETRIX Native
                                  +-- FENLAN Native
                                  +-- ZYP Native
                                  +-- SDPC JPEG/BMP + optional HEVC decoder
                                  +-- CSP pure Go / ReadAt-style ranges
                                  +-- HWP runtime SDK adapter
                                  +-- TRON runtime SDK adapter
```

Spring Boot 仍只调用 Python Worker。Python 是唯一解析门面：SVS 固定走 OpenSlide；受支持的厂家格式按 Go `/api/formats` 动态路由。Go 不可用时，SVS 不受影响，Go 格式返回 `PARSER_UNAVAILABLE`。

## 共享缓存

Worker 从 MinIO 下载到：

```text
/data/slides/{slideId}/{sanitizedFileName}
```

Compose 的 `slide_cache` 对 Worker 为读写，对 Go Parser 为只读。Go 不重复访问 MinIO。Go 只接受数字 `slideId`，从对应目录选择最新的非空普通文件，并拒绝符号链接和路径逃逸。

## Go API

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/health` | 服务状态、Parser 数量、CGO 状态 |
| GET | `/api/formats` | 动态格式能力 |
| POST | `/api/slides/{id}/analyze` | 元数据和统一层级 |
| GET | `/api/slides/{id}/thumbnail` | JPEG 缩略图 |
| GET | `/api/slides/{id}/label` | JPEG 标签图 |
| GET | `/api/slides/{id}/macro` | JPEG 宏观图 |
| GET | `/api/slides/{id}/tiles/{level}/{x}/{y}` | 256 x 256 JPEG Tile |

Go 对外层级统一为低分辨率 `0` 到高分辨率 `maxLevel`。解析器原生层级在服务端转换；边缘区域以白色补齐到 256 x 256。label/macro 不存在时返回 404，不生成伪造图片。

## 缓存与并发

ParserCache 的逻辑键是 `slideId + path + fileSize + mtime`。条目 TTL 为 30 分钟，最多 128 个；命中文件属性变化时重新初始化，并在替换/淘汰时确定性关闭原生 reader。同一切片的 Tile 串行访问其 Parser；HWP 使用每切片隔离的原生 helper 进程，TRON 保守串行化 SDK 的跨 reader 调用。

## 资源与错误边界

- HTTP：header 5 秒、read/write 30 秒、最大 header 1 MiB。
- Python 到 Go：能力/健康 5 秒、metadata/thumbnail 30 秒、tile 15 秒。
- FileStreamer 单次读取最多 64 MiB；HTTP 解析器图片输出最多 64 MiB。
- 元数据最大 2,000,000 x 2,000,000，最多 32 个对外层级；SDPC 原始层最多 16 层、单边 Tile 尺寸最多 4096、索引总量最多 4,000,000。
- 未支持格式返回 415；缺 SDK/Decoder、损坏或不兼容文件返回 422；缓存不存在返回 404；panic recovery 返回 500 且不会伪装成功。

## 可选原生依赖

默认镜像使用 Debian bookworm/glibc 并设置 `CGO_ENABLED=1`。CSP 为纯 Go，按 128 字节头、Sequence 元数据和 pixel-data 相对偏移进行分段读取，不需要 SDK。HWP/TRON adapter 编译进二进制，但厂家 `.so` 只从 `/opt/vendor-libs` 只读挂载并在运行时动态加载，绝不进入镜像或 Git；缺失 SDK 时服务仍健康。HWP 已在当前本地 SDK 和兼容真实文件上人工验收为 `AVAILABLE`；CSP/TRON 在完成同等验收前保持 `TEST_DATA_REQUIRED`。
