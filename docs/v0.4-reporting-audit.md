# v0.4 上报模块审计

## 需求映射

| 需求 | v0.3 可复用 | v0.4 增量 | 验收 |
|---|---|---|---|
| R2.1 规范驱动生成 | `ReportPackageBuilder`、JSON/XML/CSV/ZIP/病理 ZIP Exporter | `report_spec`、版本、字段映射、DEMO 规范 | 创建规范并生成文件 |
| R2.2 任务调度 | `report_plan`、Spring Scheduling、失败重试 | `report_job`、优先级、幂等、执行记录、WEEKLY/MONTHLY | 相同计划时间唯一且高优先级先执行 |
| R2.3 预审核 | 既有质量校验 | 规则、问题、覆盖审计、重新审核、发送硬拦截 | ERROR 阻断，覆盖需权限 |
| R2.4 安全传输 | HTTP/File Sender | Transfer Session/Chunk、Mock Receiver、SHA-256、TLS/mTLS 配置 | 中断后从服务端缺失 Chunk 恢复 |

旧批次允许 `job_id=NULL`，旧 Sender 不删除。正式卫健委字段、接口、签名、证书和断点协议尚未提供，不能在代码中伪造。
