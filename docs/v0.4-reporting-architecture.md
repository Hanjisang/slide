# v0.4 架构

```text
ReportSpec(versioned)
       -> ReportPlan -> ReportJob(unique plan_id + scheduled_at)
       -> JobItem snapshot -> ReportPrecheck/Issues/Overrides
       -> existing ReportPackageBuilder + Exporters -> ReportBatch
       -> existing HTTP/File Sender or ResumableHttpReportSender
       -> TransferSession/Chunk -> Mock Receiver -> SHA-256 verify
```

数据库事务仅覆盖状态和元数据；文件生成与 Chunk 上传在事务外执行。Chunk 默认 8 MiB，限制 1–64 MiB，上传读取使用 `RandomAccessFile`，不会将大文件整体加载到内存。
