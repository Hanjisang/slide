## 7. 已知限制

- HWP 的 `AVAILABLE` 结论绑定当前本地 Linux SDK 与兼容真实文件；原生 helper 将 SDK 崩溃隔离在 Go 服务之外。另一份生成测试文件不被当前 SDK 接受，不计入兼容样本通过率。
- TRON 的 `AVAILABLE` 结论绑定私有 vendor 镜像内的当前 Linux SDK/ABI；厂家二进制不进入 Git，交付环境仍需确认 SDK 镜像分发许可。
- TRON 样本为稀疏归档：合法视口中的缺失原始 Tile 按白色背景返回，不视为解析失败。
- CSP 为纯 Go 路径，不依赖厂家 SDK；格式来源与第三方声明需随交付保留。
- SDPC FFmpeg 子进程开销高于纯 Go 图片路径。
- TMAP/ZYP 的纯背景 Tile 只记录内容告警，不能仅凭全白判坏片。
- 本轮 no-cache 构建曾将宿主 C: 写满并导致 Docker Desktop/MySQL 停止；清理可恢复缓存并重启后，数据库、全部容器和应用链路均已恢复并重新验收。
