# 医疗数据及数字病理上报平台验收测试步骤 v2.0

## 1. 上报任务调度管理

1. 打开“医疗数据上报 / 上报任务调度管理”，点击“新增调度任务”。
2. 选择上报模板和平台，设置“每日”、执行时间和“高”优先级，保存。
3. 在列表核对周期、执行时间、优先级、上次执行、下次执行和启用状态；点击“立即执行”验证任务进入执行记录。

## 2. 数据预审核闭环

1. 打开“医疗数据上报 / 待上报数据”，勾选数据并点击“创建上报任务”。
2. 进入“数据预审核”，点击“查看问题”，核对数据对象、字段、当前值、错误信息和修改建议。
3. 点击“修改”保存新值，再点击“重新审核”；只有审核通过的任务才出现“生成上报文件”。

## 3. 安全传输保障

1. 打开“医疗数据上报 / 安全传输保障”，查看文件大小、已上传大小、进度、分片、最后活动时间和当前状态。
2. 对传输中的记录点击“暂停”，确认进度保留；再点击“继续”，确认从原分片继续。
3. 将演示接收端切换为失败后点击“失败重试”，核对失败状态、重试结果和 SHA-256 完整性校验。

## 4. 多平台上报支持

1. 打开“医疗数据上报 / 多平台上报”，核对上报平台、主管部门、地区、规范版本、文件格式、频率和传输方式。
2. 点击“新增上报平台”，填写示例平台规范并保存。
3. 确认新增平台与内置项均可被调度任务选择；页面明确标注示例规范不代表正式卫健委规范。

## 5. 数据清洗转换

1. 打开“医疗数据采集与治理 / 数据清洗转换”，查看清洗规则、字段转换规则和标准化字典。
2. 进入“转换测试”，选择源系统 HIS、业务类型患者，输入 `{ "gender": "1", "name": " 张三 " }`。
3. 点击“执行清洗”，核对返回结果和字段转换前后值；结果来自真实 MappingEngine。

## 6. 数据校验机制

1. 打开“医疗数据采集与治理 / 数据校验”，在“校验规则”中查看或新增 NOT_NULL、RANGE、ENUM、REGEX、UNIQUE、CROSS_FIELD、CROSS_RECORD 规则。
2. 在“异常数据”中打开异常，执行人工修正或忽略。
3. 点击“重新校验”，核对状态由待处理/不通过变为已修正或通过。

## 7. 多格式数字切片显示

1. 打开“数字切片 / 多格式数字切片显示”，核对 TMAP、KFB、TRON、MDSX、SVS、SDPC、DMETRIX、FENLAN、ZYP、HWP、CSP 共 11 种格式。
2. 上传一张真实 SVS，等待状态变为“可用”；若失败，核对页面显示失败原因或“解析组件不可用”，不得将其提示为解析完成。
3. 点击“预览”，验证缩略图、低/中/高倍率 Tile、平移和缩放；必要时使用“重新解析”。

## 8. 数字切片管理与归档

1. 打开“数字切片 / 数字切片管理”，查询切片文件信息、存储位置和归档状态。
2. 选择启用的 ARCHIVE 存储目标，点击“归档”；非 READY 切片应被禁止归档。
3. 核对复制、大小校验、MD5 校验和归档进度；成功后归档状态为“已归档”，失败时显示具体原因。

## 9. 系统管理功能

1. 打开“系统管理 / 用户管理”和“权限管理”，编辑用户角色及权限。
2. 打开“日志管理”，按用户、模块和时间查看操作记录。
3. 打开“资源管理”和“质控管理”，核对 CPU、内存、磁盘、JVM、MySQL、MinIO、Slide Worker、Go Parser、存储目标、异常和告警汇总。

## 10. 基础数据功能

1. 打开“基础数据 / 报告模板设置”，编辑模板名称、报告类型、文件格式和启用状态。
2. 打开“基础数据 / 病理号规则设置”，新增规则 `P + yyyy + - + 6位流水号`，点击“预览”核对 `P-当前年份-000001`。
3. 打开“基础数据 / 标本类型管理”，新增、编辑、停用或删除 `SPECIMEN_TYPE` 字典项。

## 11. 医疗数据上报完整链路

1. 按第 2 节创建并通过一个预审核任务。
2. 点击“生成上报文件”，再在“上报记录”点击“开始上报”。
3. 核对成功数量、失败数量、失败原因、开始/结束时间和最终状态；预审核不通过时应保持“已阻断”，不可生成或发送。

## 验收记录

正式平台地址、主管部门生产规范、客户端证书和厂商 SDK 由部署环境提供。演示环境可使用内置示例平台和模拟接收端；测试记录中应注明所用环境及真实切片文件名。
