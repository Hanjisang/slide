## SDK 审计

- 本地 HWP SDK：Linux amd64 ELF；`pthread`、`libstdc++`、`libm`、`libgcc_s`、`libc` 和 loader 均可解析。
- 本地 TRON SDK：Linux amd64 ELF；`libgcc_s`、`librt`、`pthread`、`libm`、`libdl`、`libc` 和 loader 均可解析。
- CSP：未发现可供本轮合法调用的 SDK；许可状态也未确认。
- 默认 Go 镜像仍为 `CGO_ENABLED=0`，不包含、复制或链接上述厂家二进制。

ELF/`ldd` 通过只证明动态依赖可加载，不证明函数 ABI、对象生命周期、线程模型、license 初始化或样本版本兼容。HWP/TRON 因此归类为 `COMPATIBILITY_REQUIRED`，而不是 `AVAILABLE` 或笼统的“缺文件”。

## 安全边界

- FileStreamer 拒绝负范围、越界、非普通文件和单次超过 64 MiB 的读取。
- Registry 校验宽高、层级和 block size，并在 parser 外层恢复 panic。
- 服务只解析 `/data/slides/{slideId}`，拒绝任意路径、非法 ID 和越出缓存根目录的符号链接。
- Parser 缓存按路径、大小、mtime 失效，TTL 30 分钟、最多 128 项，同一切片互斥访问。
- verifier 日志默认静默并脱敏真实路径/文件名；JSON 只写匿名别名。
- SDPC 对尺寸、层数、索引和编码图像大小设限，HEVC 使用标准 FFmpeg runtime。

## 许可与 Git

真实切片、患者信息、`.so`、`.dll`、厂家头文件和 license 文件禁止进入 Git。获授权的本地依赖只能放在忽略目录中；仓库只提交验证工具、测试、必要兼容修复和文档。
