# P34 SDPC HEVC 真实切片专项

## 结论

真实 SDPC Tile payload 是标准 HEVC Annex-B elementary stream，不是 HVCC，也没有需要剥离的厂商前缀。代表性 payload 以 `00 00 00 01 40` 开始，包含 VPS、SPS、PPS 和图像 slice/IDR NAL；Alpine FFmpeg 6.1.2 可直接解码为 `672x672` RGBA。

原代码在 `SliceFormat == 4` 时直接返回 `DECODER_REQUIRED`。仓库没有 `libDecodeHevc.so` 的 ABI、头文件或 wrapper，因此无法证明厂商库除 HEVC 解码外承担了私有封装工作。标准 HEVC 验证证明本样本不需要该库。

## 真实样本诊断

仅对原始文件只读读取，未修改或提交样本。技术 metadata：

- format: SDPC
- source dimensions: `83328 x 91392`
- tile dimensions: `672 x 672`
- levels: `8`
- header codec: HEVC (`SliceFormat=4`)
- representative payloads: 2.7 KB 至 149.6 KB；边缘空白 Tile 可低于 1 KB

层级 1、2、3、4、5、6、7、8 的 payload 均出现 Annex-B 起始码；前置 NAL 类型包含 VPS/SPS/PPS，随后为 slice/IDR 数据。最底层另有 per-layer `Format=1` 的 BMP Tile，修复后按层级 codec 字段分发，不再错误地将其送入 HEVC 解码器。

## 修改方案

新增 `Decoder` 接口和 `FFmpegDecoder` 实现。HEVC 通过 `exec.CommandContext` 使用 stdin/stdout 管道解码：

`ffmpeg -f hevc -i pipe:0 -frames:v 1 -f rawvideo -pix_fmt rgba pipe:1`

不使用 shell 拼接或临时文件。Docker runtime 安装 Alpine 仓库固定版本 FFmpeg 6.1.2。JPEG、BMP、PNG、TIFF、HEVC 现在按 codec 类型明确分发。

## 安全措施

- HEVC payload 最大 64 MiB。
- Tile 宽高必须在 1..4096。
- FFmpeg 单次解码超时 10 秒。
- 捕获 stderr，限制错误文本长度；非零退出、超时和缺少 ffmpeg 均返回 error。
- raw RGBA 输出长度必须严格等于 `width * height * 4`。
- 原有 SDPC offset、length、文件范围、索引数量和分配限制保留。

## 真实验收

样本 metadata：`83328 x 91392`，8 levels。

- analyze: HTTP 200
- thumbnail: HTTP 200，JPEG
- level 0: `(0,0)`, `(1,2)`, `(1,1)`，均 HTTP 200
- middle levels: level 1、2、3、4、5 多个坐标，均 HTTP 200
- max level: level 7 `(0,0)`，HTTP 200
- edge: level 0 `(1,2)` 和 level 5 `(30,30)`，HTTP 200
- 所有响应为 JPEG，Go 服务已实际解码并重新编码；FFmpeg signalstats 显示多个区域存在非零像素范围，不是空白伪成功

HTTP 真实样本已验证；浏览器自动化未执行，状态记录为 `BROWSER_NOT_VERIFIED`。

## 性能与并发

10 个真实 Tile（包括多个层级和边缘坐标）：

- min: `175 ms`
- avg: `302 ms`
- p95: `727 ms`
- max: `727 ms`

并发请求：5 个并发全部 HTTP 200，总耗时约 `1.27 s`；10 个并发全部 HTTP 200，总耗时约 `3.15 s`。当前实现每个 Tile 启动一次 FFmpeg 子进程，这是已知性能技术债；未观察到 panic、输出串扰或临时文件冲突。

## 限制

本结论基于当前真实样本和标准 Annex-B HEVC。其他 SDPC 厂商版本、加密 Tile、不同 codec profile 仍需独立样本验证。原厂 `libDecodeHevc.so` 的 ABI 未提供，无法验证其内部实现；本专项仅证明标准 FFmpeg 路线足以处理当前真实样本。
